#### HLA-Face：面向低光照人脸检测的高低层联合自适应

<!-- more -->

本文任务是，如何充分利用现有的正常光数据，如何将在正常光照数据上训练的人脸检测器适配到未标注的弱光照图像数据中。

#### 问题

这项任务的挑战在于：

一、正常光照数据和低光数据之间有着像素级和目标级的大且复杂的差距：

![image-20250915153044156](/images/image-20250915153044156.png)

1、一个是像素级外观的差距，指的是同一张图，变亮和变暗的区别。比如亮度不足、相机噪声、颜色偏置等。这可以通过图像增强技术在一定程度上缓解。

2、另一个是正常和低光场景之间的物体级语义差异，指的是两张图**内容本身就不同**。低光照场景（如夜晚街道）**多了很多正常光照下不存在或不显著的物体（路灯、车灯）**，这些物体是低光照环境所特有的、主动发光的光源。**一个在白天训练的模型，可能从未“学习”过这些发光物体是什么**，以及它们对周围环境（如人脸）会产生什么样的光照影响。**它们会产生强烈的高光、不均匀的阴影、甚至改变人脸的颜色，这与正常光照下的情况完全不同**。因此，正常光和低光场景之间的差异，**不仅仅是把图片调暗了那么简单**，而是整个场景的**“内容和逻辑”都发生了改变**。**模型需要理解这种由特定物体（光源）带来的全新光照逻辑**。这是图像增强方法无法解决的，它无法“无中生有”地创造出这些物体及其产生的光照效果。

虽然特征自适应方法试图考虑这两方面差距，但是效果有限。

二、数据不足，并且目前很多低光照图像目标检测都需要依赖标签，限制了灵活性和鲁棒性。

#### 创新

为了能够应对上面所说的两种数据之间的像素级和目标级的差距，作者提出了一种联合低级和高级特征自适应的方案。

在低光照图像和正常光照图像之间设置中间状态，并基于这些状态自适应相应的高级表示**（意思是下面说的还可以自适应的减小高级距离）。**

![image-20250915153338229](/images/image-20250915153338229.png)

1、低级特征适应，设计了双向方案，**通过增强低光数据和变暗正常光数据来创建中间状态减小低级距离**，与L-to-H或H-to-L单向平移相比，**双向平移：L-to-E(L)和H-to-D(H)，不仅可以缓解自适应的难度，还可以**为特征级自适应提供更多的工具，**通过将多个状态的特征空间推向彼此来减小高级距离。**

2、高级特征适应，基于构建的中间状态，引入了**跨领域自监督学习进行特征适应**。**通过基于上下文的对比学习，全面地缩小了多个域之间的特征距离**，进一步增强表示。

#### 具体来说

![image-20250915154057404](/images/image-20250915154057404.png)

#### 双向低级自适应

- 低层自适应（像素层面的调整）的挑战在于两个方面。

  1. **正常与低光场景之间还同时存在着高层语义上的差异**（不仅是亮度不同这种底层差异，还有场景内容层面/语义层面的差异，就像我们前面说的，**低光场景中多了路灯、车灯、广告牌这些内容，而正常光照场景中没有**）。**这种内容上的差异会干扰那些只做像素级转换的模型**（如CycleGAN、CUT等），把本属于夜晚场景的物体（如路灯）错误地添加到转换后的图像中，导致生成结果不伦不类。

     ![image-20250915155518421](/images/image-20250915155518421.png)

     模型在学习“夜晚风格”时，发现DARK FACE数据集里很多图片都带有**路灯、车灯等发光体**。于是模型**错误地认为“路灯”也是“夜晚风格”的一部分**。当模型处理一张白天的人脸时，它**不仅会把图片调暗，还会“无中生有”地在人脸上画一个路灯，或者在人的身体上生成奇怪的光斑。**

  1. **弱光增强本身的难度**。现有的一些低照度增强方法都是按照人类视觉的方式进行增强，不是考虑机器视觉。现在的一些方法画出了暗区域的边缘，有噪声的部分还是黑的，增强的对比度可能会影响检测性能。此外，DARK FACE中的图像有密集的噪声和颜色偏差，而现有的去噪和颜色重构方法不足以解决这些问题

- 解决方法。

  - 作者提出了双向低级适应方案，将正常光照图像退化为弱光图像是一个复杂的过程，可以分解成三个因素：光照、噪声、颜色偏差。

    把一张**正常光图像H，人为地加上噪声和颜色偏差，变成一张“伪低光”照片D(H)。**

    把一张**真实低光照片 L，用算法提亮，变成一张“伪正常光”照片 E(L)。**

    与L和H相比，E(L)和D(H)更相似。**现在模型要学习的转换就变成了从 H -> E(L) 和 D(H) -> L**。这两个任务中的图像**内容是相似的**，**不再有“路灯”这种语义上的巨大差异。模型只需要专注于处理亮度、噪声、颜色这些“要素”级别的变化就行了。**

1. Brightening

   - 调整亮度的同时不会让图像产生噪声和色偏(调整亮度后不需要额外再去噪和颜色重构)，而且**弱光图像存在光照不均匀的问题，有些人脸可能会被路灯提亮，而有些则可能会被严重的黑暗覆盖**，因此我们还需要**防止曝光过度和曝光不足**。

     --------------------------------------------------------------------------------------------------------------------------------------------------------------

     (1)、如果使用简单的线性提亮方法，比如把整张图片所有像素的亮度值都乘以2。那么**对于黑暗区域**：一个亮度为20的像素点，乘以2后变成40，确实变亮了，效果不错。**而对于已被路灯照亮的区域：一个亮度已经是150的像素点，乘以2后变成300。但在标准的图像格式中，亮度最大值是255。所以这个点就会变成255，即“纯白色”，完全失去了细节。这就是曝光过度 (over-exposure)**。

     **线性方法就像一个“一刀切”的政策，它无法同时照顾到暗部和亮部的不同需求，必然会导致一部分区域效果好，另一部分区域效果差（甚至更差）。**

     (2)、非线性曲线映射就好比一个**“精细化调节”**的工具。**能够对图像中不同亮度的区域做不同程度的调整，这恰好是解决“光照不均匀”问题的最理想工具。**

     面对“光照不均匀”的人脸，非线性曲线可以**大幅提亮暗部 (防止曝光不足)**：对于输入亮度很低（比如0-50）的像素，我们可以让曲线变得非常**“陡峭”**。这意味着，一个微小的亮度变化（比如从20提升到21）会被映射成一个巨大的输出变化（比如从40提升到60）。这样就把黑暗中的细节给“拉”了出来。

     也可以**轻微调整甚至压缩亮部 (防止曝光过度)**：对于输入亮度已经很高（比如200-255）的像素，我们可以让曲线变得非常**“平缓”**。这意味着，即使输入亮度有变化，输出亮度也只会有微小的改变，或者干脆都映射到一个比较高的值（但不是纯白的255）。这样就保住了高光区域的细节，防止其变成一片死白。

     ------------------------------------------------------------------------------------------------------------------------------------------------------------------

     所以使用了基于**非线性曲线映射**方法，由迭代二次曲线$$ L E ( \cdot ) $$构成：

     $$ L E ( x , A ) = x + A x ( 1 - x ) ,$$

     $$ L E _ { n } = L E ( L E _ { n - 1 } ; A _ { n } ) ,$$

     $$L E _ { 0 }$$是输入图像，$$ L E _ { n }$$是迭代n次的结果。$$ A _ { n }$$​是由神经网络预测出的像素级三通道调整图。与常见的端到端或基于Retinex的深度增强方法相比，曲线映射不会引入额外的噪声或伪影。使用了一个7层具有对称Skip-connection的CNN和相应的目标函数。

   - 如果增强太多会带来更多的噪声，如果只进行一个弱增强的话，噪声就会隐藏在黑暗中，成像质量更好，但是弱增强会导致许多人脸仍然被黑暗覆盖。所以作者提出**强增强**。将上述公式中的迭代次数加倍，并扩大曲线估计网络，**模型可以以更高的亮度增强图像。缺点是随之而来的噪声和颜色偏差**，但在下面的H -> D(H) 过程中会处理。

2. 噪声合成。

   - 虽然像素级距离可以通过调整亮度来缩小，但减少E(L)和H之间的差距仍然比较困难。因此，我们进一步将剩余的差距分解为**颜色和噪声**。

   - 噪声和颜色相关，噪声本身就是带颜色的，通常是红、绿、蓝的杂色斑点。并且由于感光元件（CMOS/CCD）对不同颜色的光（红、绿、蓝）敏感度不同，经过相机内部处理后，不同颜色通道的噪声强度也不同。例如，蓝色通道通常是噪声最大的。在一张照片里，深蓝色区域的噪声模式，和亮黄色区域的噪声模式是完全不一样的。

   - 所以，可以先分析和计算出从正常光图像H到提亮后的低光图像E(L)之间，还存在哪些**颜色上的差异**。这一步等于得到了一个**”颜色校正图“或者说“颜色指导图”。**

     然后**用颜色引导噪声合成**，在生成噪声往图H上添加的时候，他们不是盲目地添加，而是参考上一步得到的“颜色指导图”。这个过程可以理解为一个生成模型，它的输入不仅是原始图像，还包括了目标颜色信息。

     所以为了让合成的噪声尽可能逼真，我们不能把它当成一个孤立的过程。我们应该**先搞清楚目标图像的“颜色特征”，然后利用这些特征作为“先验知识”或“条件”，去指导一个可控的噪声生成过程。**这样做避免了“一刀切”式地添加不真实的均匀噪声，而是为图像的每一个不同颜色、不同亮度的区域“量身定制”了最合适的噪声，从而让最终模拟出的低光图像D(H)在细节上更接近真实的低光图像L。

   - 首先通过$$d=25$$和$$ \sigma=75$$的强双边滤波器模糊E(L)。模糊后的结果$$ E ( L ) _ { b l u r }$$作为颜色引导噪声合成。然后，训练一个Pix2Pix将模糊后的结果$$ E ( L ) _ { b l u r }$$转移到所需要的E(L)。最后，我们以同样的方式模糊H，并使用训练好的Pix2Pix添加噪声。最终得到的$$H _ { n o i s e }$$成功地模仿了E(L)的噪声模式。它们在颜色分布上的差异将在下一步处理。

3. 颜色抖动(修正)：

   - $$ D ( H )$$的颜色分布要匹配$$ E ( L )$$，基于统计学分析，设置了亮度抖动区间(0.4, 1.2)，对比度抖动区间(0.6, 1.4)，饱和度抖动区间(0.6, 1.4)，色度抖动区间(0.8, 1.2)。

#### 多任务高级适应

大多数特征自适应方法基于图像对齐、伪标签训练和对抗学习，但是图像对齐和伪标签训练不能处理巨大的差距，而对抗性学习并不稳定，我们转而**充分利用图像本身的自然信息**，即自监督学习，**通过强制自监督学习分类器跨域共享，强制将特征映射到相同的高维子空间，从而缩小高层差距。**

---------------------------------------------------------------------------------------

解释一下这句话的意思：

通过强迫模型用**同一个‘大脑’**（即共享的分类器）去理解**来自不同领域（正常光和低光）的图像**，我们也就强迫模型必须学会用一种**通用语言**（**即相同的特征子空间，也就是上面说的强制将特征映射到相同的高维子空间**）来描述这些图像，这样一来，不同领域之间的**理解障碍（高层语义鸿沟）**就被消除了。

举个例子：

**两个领域 (Domains)**：一个只说中文的人（正常光图像），一个只说英文的人（低光照图像）。

**特征 (Features)**：每个人脑中对“苹果”这个概念的内部表述。

**高层语义鸿沟 (High-level gap)**：两个人无法直接交流，因为他们对“苹果”的表述（语言）不同。

**自监督学习分类器 (Self-supervised learning classifier)**：一个翻译老师。

**共享分类器 (Shared classifier)**：我们**只聘请一位既懂中文又懂英文的翻译老师**，而不是请一个中翻英和一个英翻中老师。

**相同的特征子空间 (Same high dimensional subspace)**：这位翻译老师为了完成工作，在自己脑中形成的一个**不依赖于具体语言的、对“苹果”这个物体的抽象概念**。

自监督学习是一种让模型自己给自己出题来学习的方法。比如，把一张图片随机旋转0°、90°、180°或270°，然后让模型去预测这张图被旋转了多少度。为了能正确完成这个任务，模型必须先“看懂”图片的内容（比如它得先认识到人脸是正的还是倒的）。这个“预测旋转角度”的模块就是**自监督学习分类器**。

共享就是作者用**同一个旋转角度预测器**，去分别处理正常光图像和低光照图像。无论是给它一张亮的脸，还是一张暗的脸，都让这**同一个分类器**去判断旋转了多少度。

**高维子空间 (High dimensional subspace)**：可以把它理解为模型用来表达这些特征的“数学语言”或“表示空间”。

因为只有一个分类器，它要能同时处理正常光和低光两种图像，它就必须学会提取一种**通用的、不受光照影响的特征。**模型为了让这同一个分类器能正常工作，就会被迫学习去忽略“亮度”、“噪声”这些属于不同领域的干扰信息，而专注于提取这种最本质的语义特征。最终结果就是，一张亮的人脸和一张暗的人脸，**在模型内部都会被用非常相似的“数学语言”（即映射到特征空间中的邻近位置）来表达。**

一张正常光人脸的特征和一张低光照人脸的特征，在模型看来变得非常相似了。这样一来，一个在正常光数据上训练好的人脸检测器，拿到低光照图像的特征后也能认识并处理了，因为特征的“语言”已经被统一了。鸿沟自然就被填补了。

这是一种非常巧妙的“特征对齐”方法。它不直接去修改图像像素，而是在特征层面，通过设计一个“共享”的自监督任务，**强迫模型自己去学习一种不受领域（光照）变化影响的、更本质、更通用的特征表达方式**，从而解决了正常光和低光照两个领域之间的语义差异问题。

---------------------------------------------------------------------------------------

为了实现：无论输入给模型的是一张**干净的正常光图像 (H)**，一张**被提亮了的低光图像 (E(L))**，还是一张**被人工模拟成低光的正常光图像 (D(H))**，只要它们的内容（比如里面的人脸）是相同的，模型最终输出的特征向量就应该非常接近。

首先通过跨域的、基于上下文的自监督学习来搭建H与E(L)之间的桥梁，让模型学习到，一张提亮后的低光图像E(L)和一张干净的正常光图像H，虽然一个有噪点和色偏，一个没有，但它们的**核心内容和结构是相同的**。这一步强迫模型学会**忽略真实的噪声和色偏**。

然后通过跨域对比学习来搭建H与D(H)之间的桥梁，让模型学习到，一张干净的正常光图像H和我们**亲手把它变脏的图像D(H)是一对正样本**。**因为D(H)是由H直接生成的，内容完全一致，所以这是一个非常强的监督信号。这一步强迫模型学会忽略我们模拟的噪声和色偏。**

#### 搭建H与E(L)之间的桥梁

基于上下文的**自监督学习设计代理任务**（我们的**真正目的**并不是让模型去完成这个任务本身，而是希望模型**在完成这个任务的过程中，能学到一些通用的、有价值的图像特征**），通过这些任务模型可以**学习理解物体的空间上下文**。在这里，作者**使用拼图方法**（效果最好）。**将3×3的补丁组装成一个完整的图像，并将补丁排列数设置为30，即30分类问题**。

$$ L _ { j i g } ^ { E ( L ) } = C _ { c } ( F _ { j i g } ^ { E ( L ) } , p _ { j i g } ^ { E ( L ) } ) ,$$

$$ C _ { j i g } ^ { H } = C _ { c } ( F _ { j i g } ^ { H } , p _ { j i g } ^ { H } ) ,$$

$$p_{jig}$$表示排列的标签，$$ L _ { c }$$为交叉熵损失。$$F_{jig}$$表示相应域中提取出来的特征（写在这个变量右上方的字母表示 **是在对应域下的值**）。

E(L)和H共享一个 **强制把语义特征映射到相同空间** 的分类头，因此使得高级特征之间的差距减少，最终损失函数:

$$ L_ { E ( L ) \leftrightarrow H} = L _ { j i g } ^ { E ( L ) } + L _ { j i g } ^ { H } .$$

#### 搭建H与D(H)之间的桥梁

对比学习的想法是，给定一个查询v，判断这个v是“正样本对$$ v ^ { + }$$”还是“负样本对$$v ^ { - } = v _ { 1 } ^ { - } , v _ { 2 } ^ { - } \cdots , v _ { N } ^ { - }$$”。**通过点积的方法测量相似性**，目标函数$$ L _ { q } ( v , v ^ { + } , v ^ { - } )$$是： 

$$ L _ { q } = - \log \left[ \frac { \sigma ( v , v ^ { + } ) } { \sigma ( v , v ^ { + } ) + \sum _ { n = 1 } ^ { N } \sigma ( v , v _ { n } ^ { - } ) } \right] ,$$

$$ \sigma ( x , y ) = e x p ( x \cdot y / \tau ) ,$$

 $$\tau$$是一个温度超参数。直观地说，这是一个(N+1)的分类问题。

---------------------------------------------------------------------------------------

什么是对比学习？

可以把对比学习想象成一个教机器“物以类聚，人以群分”的游戏。我们给模型看一张**“基准图片” (Anchor)**。然后，我们再给它看一张和基准图片**“是同一类”**的图片，我们称之为**“正样本” (Positive Sample)**。同时，我们还给它看很多张和基准图片**“不是同一类”**的图片，这些是**“负样本” (Negative Samples)**。

调整模型，使得在特征空间中，**“基准图片”和“正样本”的特征表示被拉得越来越近**，同时**“基准图片”和所有“负样本”的特征表示被推得越来越远**。通过这个过程，模型就学会了什么东西是本质上相似的，即使它们表面看起来有些许不同。

---------------------------------------------------------------------------------------

为了减小H和D(H)之间的差距，我们利用了对比学习可以拉近正样本之间距离的这一特性。具体来说：**我们将来自图像H的一个patch和来自图像D(H)的对应patch，定义为一对正样本。**（虽然它俩一个清晰、一个“脏”，但它们的**底层内容是完全一样的**，因为D(H)是同一张H图像在经过人工添加噪声和颜色偏置之后，模拟出的低光照版本）。

作者不是用整张图，而是从图中裁剪出一小块一小块的patch区域。模型的目标是**让干净的Hpatch和有噪声的D(H)patch在特征层面尽可能相似（拉近）**，同时**让我们这个patch（比如我们取的是左眼patch）的特征和数据集中任何其他patch（比如另一张图的鼻子、或者同一张图的嘴巴）的特征尽可能不同（推远）**

反之亦然，也就是说这个过程是双向的，作者既把D(H)的patch当做Hpatch的正样本，也把H的patch当做D(H)patch的正样本，来回进行，以加强学习效果。

通过把一张干净图片H 和它的“脏”版本D(H) 的对应部分定义为正样本，并利用对比学习去“拉近”它们，**模型被迫学会忽略那些使图像变“脏”的因素（即噪声和颜色偏差），而去关注图像最本质的内容信息**。最终，模型就能为H 和 D(H)生成几乎一样的特征，提高了二者的特征相似度，从而达到了“缩短二者距离”的目的。

![image-20250915212703976](/images/image-20250915212703976.png)

作者还在H和D(H)本身上引入了单域对比学习，以使特征更好。在实现中，通过将$$ D ( \cdot )$$视为增强的一部分来简化上述四个损失：

$$ L _ { H \Leftrightarrow D ( H ) } = L _ { q } ( D _ { i } ^ { * } ( H ) , D _ { j } ^ { * } ( H ) ^ { + } , D _ { k } ^ { * } ( H ) ^ { - } ) ,$$

其中$$ D ^ { * } ( H )$$有50%的概率是H，50%的概率是D(H)。训练时，使用动量对比度（MoCo）进行优化。

#### 增强E(L)

作者还发现，通过对比学习增强E(L)的特征是有益的：

$$ L _ { E ( L ) \uparrow } = L _ { q } ( E ( L ) , E ( L ) ^ { + } , E ( L ) ^ { - } ) .$$

#### 最终目标。

模型以多任务方式学习。将$$ L_ { d e t }$$表示为检测损失，最终目标是：

$$ L = \lambda _ { d e t } L _ { d e t } + \lambda _ { E ( L ) \leftrightarrow H}  L _ { E ( L )\leftrightarrow H }  \\ + \lambda _ { H \leftrightarrow D ( H ) } L_ { H \leftrightarrow D ( H ) } + \lambda _ { E ( L ) \uparrow } L_ { E ( L ) \uparrow } ,$$

其中$$ \lambda s$$是平衡不同损失的超参数。
